About

I work close to the hardware side of Android: recovery images, kernel source and firmware. My repositories cover the Redmi 13C 5G, Redmi 13R 5G, Poco M6 5G, Redmi 15 5G, Poco M7 Plus 5G and Poco C31.

My profile lists Android 13+, Linux kernel 5.15 and reverse engineering as my areas. Outside of code I keep learning about electronics.

Focus areas

  • Recovery development

    TWRP device trees for Xiaomi, Redmi and Poco phones, written in Makefile and C++.

  • Kernel source

    Kernel source for the spring platform, forked from Xiaomi's open source kernel and written in C. Linux kernel 5.15.

  • Firmware and reverse engineering

    A GitHub Actions workflow that dumps device firmware with the DumperX script.
